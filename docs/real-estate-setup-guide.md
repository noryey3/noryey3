# Real Estate Outreach Automation — Setup Guide

Complete step-by-step instructions to go from zero to a fully automated cold outreach system.
Estimated setup time: **2–3 hours**.

---

## Prerequisites

- [ ] **Make.com account** (free tier works for low volume; Pro recommended)
- [ ] **Airtable account** (free tier is fine)
- [ ] **Gmail / Google Workspace** account
- [ ] **Google Calendar** (Workspace for appointment scheduling)
- [ ] **Google Drive** (for lease docs)
- [ ] **Google Sheets** (for prospect list)
- [ ] **Trello account** (free tier is fine)
- [ ] **Squarespace account** (optional — only if you have a property listing website)

---

## Phase 1: Set Up Your Prospect List

### 1.1 — Create your Google Sheet

1. Create a new Google Sheet named `RE Prospect Tracker`
2. Set up Sheet 1 as described in `google-sheets/prospect-tracker.md`
3. Add columns A–L exactly as specified
4. Fill in at least 20–50 prospects before activating the automation

### 1.2 — Research prospects

Where to find people who might lease your space:
- **Google Maps** — search for your target business type near the space
- **Yelp** — filter by business category, look for ones marked "temporarily closed"
- **LinkedIn** — search for companies matching your target tenant profile
- **Local business directories** — Chamber of Commerce, BizBuySell
- **"Moving out" signals** — businesses that recently posted about relocating

### 1.3 — Score your list

Use the Lead Score rubric in `google-sheets/prospect-tracker.md`.
Prioritize scores of 7+ for the first batch.

---

## Phase 2: Set Up Airtable CRM

1. Log in to [airtable.com](https://airtable.com) → **Create a base**
2. Name it: `Real Estate Outreach CRM`
3. Create 3 tables: `Prospects`, `The Space`, `Activity Log`
4. Add all fields as defined in `airtable/real-estate-schema.json`
5. Create the views (Active Pipeline, Needs Follow-Up, Showings This Week, Hot Leads, Kanban Pipeline)
6. **Fill in "The Space" table** with your actual property details:
   - Address, size, rent, features, booking link, virtual tour URL
7. Note your **Base ID** (found in the Airtable API docs URL) — needed for Make.com

---

## Phase 3: Prepare Gmail Templates

1. Open each template from `gmail-templates/re-0*.html`
2. Customize the content for your property:
   - Replace `{{NEIGHBORHOOD}}` with your actual neighborhood
   - Update key features to match your space
   - Adjust tone to match your personality
3. Store your filled-in variables in `google-sheets/prospect-tracker.md` Sheet 3 (Space Details)
4. These variables are injected dynamically by Make.com — you don't need to manually fill them per email

---

## Phase 4: Set Up Google Calendar

Follow `google-calendar/setup.md` step by step.

Key output: **Booking link URL** — you'll need this for all email templates.

---

## Phase 5: Set Up Google Drive

1. Create the folder structure as defined in `google-drive/folder-structure.json`
2. Upload your lease template to `02 — Lease Templates/`
3. Add a `{{TENANT_NAME}}`, `{{MONTHLY_RENT}}`, etc. placeholders in the lease DOCX
   (Make.com will do a find-and-replace when generating personalized copies)
4. Note the **Template File ID** from the Drive URL — needed for Make.com RE-04

---

## Phase 6: Set Up Trello

1. Create a new board named `Real Estate Lease Pipeline`
2. Create all 9 lists as defined in `trello/real-estate-pipeline.json`
3. Install Power-Ups: Calendar, Google Drive
4. Set up Trello Automation rules (Butler):
   - Card in "Signed" → archive all other pipeline cards and post a comment

---

## Phase 7: Import Make.com Scenarios

> Import scenarios in order: RE-01 → RE-02 → RE-03 → RE-04

### For each scenario:

1. Go to [make.com](https://make.com) → **Create a new scenario**
2. Click **Import blueprint** → upload the JSON file
3. Fill in all connection credentials:
   - Airtable API key + Base ID
   - Gmail OAuth
   - Google Calendar (select `Property Showings` calendar)
   - Google Drive OAuth
   - Google Sheets ID

### RE-01 — Prospect Intake
- Copy the **webhook URL** generated by Make.com
- Paste it into Squarespace form webhook settings (if using)
- Also paste into RE-02's trigger for manual testing

### RE-02 — Outreach Sequence
- **Important:** Split into 3 separate scenarios (see notes in the JSON):
  - Scenario A (runs every 15 min): Status = New → sends email #1
  - Scenario B (runs daily at 9am): Status = Email Sent + 3 days elapsed → sends email #2
  - Scenario C (runs daily at 9am): Status = Follow-Up 1 Sent + 4 days elapsed → sends email #3
- Set all Gmail variables from Sheet 3 in Google Sheets

### RE-03 — Showing Scheduler
- Connect to your `Property Showings` Google Calendar
- Test by creating a manual calendar event with a test email address

### RE-04 — Lease Closing
- Connect your Google Drive lease template
- Set `LEASE_TEMPLATE_DRIVE_ID` to the file ID of your lease template
- Test by manually triggering with a test prospect ID

---

## Phase 8: Test the Full Flow

Run through the entire pipeline with a test email address:

1. **Add test row** to Google Sheets with your personal email
2. **Trigger RE-01** manually → verify Airtable record created
3. **Verify RE-02** sends email within 15 minutes
4. **Book a showing** via calendar link in the email
5. **Verify RE-03** fires: Airtable updated, confirmation email received
6. **Manually change status** to "Interested" in Airtable
7. **Verify RE-04** fires: lease doc generated in Drive, lease email received
8. Check all Activity Log entries in Airtable

---

## Phase 9: Go Live

1. Flip all Make.com scenarios to **Active**
2. Import your full prospect list into Google Sheets
3. Monitor Airtable dashboard daily
4. Respond personally to any replies within 24 hours — the automation gets them into the funnel,
   but human replies convert best
5. Update Trello board manually when needed (or use automation rules)

---

## Daily Checklist (once live)

- [ ] Check Airtable "Replied / Engaged" view for anyone who responded
- [ ] Check Airtable "Showings This Week" calendar view
- [ ] Review "Hot Leads" view — manually follow up on score 8+
- [ ] Add new prospects to Google Sheets as you find them

---

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Emails not sending | Check Gmail OAuth in Make.com — token may need refresh |
| Duplicate Airtable records | Verify RE-01 dedup filter formula is correct |
| Showing not triggering RE-03 | Check Calendar ID matches in Make.com |
| Lease doc not generating | Verify DOCX template has exact placeholder text matching Make.com fields |
| Follow-ups sending to replied prospects | Check status gate filter in RE-02 Scenario B/C |

---

## Variables Reference

All customizable values are stored in `google-sheets/prospect-tracker.md` Sheet 3.
Update them there and Make.com will use the latest values automatically.
